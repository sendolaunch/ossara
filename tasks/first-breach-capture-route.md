# First Breach Capture Route

Use the normal mission camera. Do not rely on photo mode or debug-only framing.

## Build Phase Setup

1. Load `?devMission=first-breach`.
2. Hold on the opening view long enough to show the rear Ward Crystal shrine, central stair route, and side breach silhouettes.
3. Select `Warden Barricade` with `1` and place it at the central stair/main choke.
4. Select `Spike-gate` with `2` and place it on a nearby lane choke so the two blockade roles are readable.
5. Briefly show the softened build/choke markers and the Ward-green spawn/lane language.

## Combat Beat

1. Start Wave 1 with `Enter` or the `Start Wave` button.
2. Let Rotlings enter through the central stair lane so the spawn gate, stairs, landing, and lane strip all appear in one shot.
3. Use left-click for the Warden sword attack.
4. Use `Q` for Ward Slam near a small crowd.
5. Use `Space` to dash/reposition.

## Reward Beat

1. After the combat read is established, show the chest/world-drop loop if time allows.
2. Let the rarity beam and tooltip/compare appear before picking up the drop.
3. Keep the Inventory / Forge panel brief; the capture should remain mission-focused.

## Closing Beat

1. Show the victory/reward panel if using a fast-forward run.
2. End by clicking `Return to Tavern` and showing the transition completes cleanly.

## Notes

- The current goal is readability: Ward Crystal focal point, lane direction, chokes, and enemy/defense contrast.
- Normal enemy physical loot drops remain disabled by design.
- Moving while attacking can still create a small glide; keep the shot focused on the approved attack pose and mission readability.
